# 공강맞춤

공강 시간에 캠퍼스 점심 메뉴를 빠르게 고르는 반응형 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도의 설치나 서버가 필요하지 않습니다.

## 포함 기능

- 음식 카테고리와 1인 예산 필터
- 한글·영문 제외 키워드 최대 3개
- 후보 식당 목록 실시간 갱신
- 2초 룰렛 추첨 및 당첨 식당 제외 재추첨
- 결과 문구 클립보드 복사
- 모바일·데스크톱 반응형 화면

현재 식당 목록은 화면에서 안내하는 것처럼 캠퍼스 주변 예시 데이터입니다. 실제 캠퍼스에 맞추려면 `app.js`의 `restaurants` 목록을 수정하면 됩니다.
